Modalidades de Integración POS

Elige operación inmediata desde el mostrador sin programación o automatización total conectada a tu software POS/ERP.

Desde Plan START

1. Escaneo de Tirilla

Captura desde Movimientos con cámara QR, lector de barras o registro de ticket.

¿Para quién es?

Comercios, cafés, boutiques, droguerías y supermercados que no desean intervenir su software de facturación y buscan operar en minutos con antifraude garantizado.

Operación del cajero:

  • 1 Abre la pantalla de Movimientos / Registrar Venta en la App o Web de NED.
  • 2 Escanea el código QR o de barras impreso en la tirilla térmica (o captura el número de factura).
  • 3 Ingresa la cédula del cliente, confirma el monto y aplica bonos o puntos en efectivo disponibles en pantalla.
  • 4 Pulsa "Registrar Compra". Si la tirilla cumple la regla de factura y no está duplicada, el cliente recibe sus beneficios al instante.

Blindaje 72 horas: Si intentan volver a registrar o escanear el mismo número de factura, NED bloquea el intento automáticamente.

PRO & ENTERPRISE • API v2.2.0

2. API Directa de NED

Integración máquina a máquina con tu POS o ERP en < 20 ms.

¿Para quién es?

Cadenas y comercios con software POS/ERP (Siigo, Alegra, Vendty, Helisa, ICG, Micros o desarrollo propio). El cajero no sale de su sistema de caja; todo ocurre vía API REST.

Capacidades clave v2.2.0:

  • 1 Pre-validación en caja: Verifica cupones (POST /api/pos/bono/validar) y saldo de puntos en efectivo (POST /api/pos/puntos/consultar) sin quemarlos en sedes no autorizadas.
  • 2 Registro ultrarrápido (< 20 ms): POST /api/pos/compra procesado en Go + Redis 7 con idempotencia de 72 horas y soporte para puntos_a_redimir y fecha_transaccion.
  • 3 Consulta y Anulación (Nota Crédito): Consulta liquidación final (GET /api/pos/compra/{id}) o anula facturas (POST /api/pos/compra/anular) revirtiendo puntos, boletas, cupones y cancelando encuestas NPS pendientes automáticamente.

Multi-Sucursal y Multi-Caja: Genera credenciales a nivel Matriz, Sucursal o Caja registradora individual, con validación de las 4 dinámicas por sede.

Preguntas Frecuentes sobre Integración POS

Resolvemos las dudas más habituales de los comercios y equipos técnicos.

¿Puedo combinar Escaneo de Tirilla y API Directa?

Sí, totalmente. Puedes tener tus cajas principales conectadas por API Directa y usar el Escaneo de Tirilla en islas, eventos o cajas auxiliares.

¿Qué ocurre si un cliente intenta usar un cupón en una sucursal no autorizada?

La pre-validación (POST /api/pos/bono/validar) responde indicando las sedes válidas y mantiene intacto el cupón en la app del cliente sin quemarlo.

¿Qué necesito para acceder a la API Directa y API Keys?

Contar con Plan PRO (aplica para una POS por sucursal) o Plan ENTERPRISE (aplica para varias POS por sucursal, sujeto a revisión). El modo Escaneo de Tirilla y el módulo web de Auditoría POS ya vienen incluidos desde el Plan START.

¿La API Directa demora el cobro o permite anular facturas?

No demora el cobro: responde en < 20 ms gracias a Go + Redis 7. Además, si hay una devolución o error en caja, puedes revertir puntos, boletas y cupones (y cancelar encuestas NPS pendientes) con POST /api/pos/compra/anular.
